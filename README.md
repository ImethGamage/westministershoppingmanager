# Westminster Shopping Manager

A Java-based Shopping Management System developed using Object-Oriented Programming (OOP) principles.

## Overview

The Westminster Shopping Manager is a desktop application designed to manage products and provide a simple shopping experience for users. The project demonstrates the practical application of core Java and Object-Oriented Programming concepts.

## Technologies

- Java
- Java Swing
- Object-Oriented Programming (OOP)

## OOP Concepts Used

- Classes and Objects
- Inheritance
- Encapsulation
- Polymorphism
- Abstraction
- Interfaces

## Main Features

- Add and manage products
- Support different product categories
- Display available products
- Shopping cart functionality
- Calculate total prices and discounts
- Graphical User Interface
